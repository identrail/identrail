# Identrail AWS Read-Only Policy

This policy is intentionally narrower than AWS managed `ReadOnlyAccess`. It grants only the metadata read calls Identrail needs to validate a connector and run the enabled machine-identity and reachability collectors. The CloudFormation template, downloadable JSON policy, and this matrix are kept in parity by regression tests.

| Service | Actions | Why Identrail needs it |
| --- | --- | --- |
| STS | `sts:GetCallerIdentity` | Confirms the assumed-role identity during setup and recurring scans. |
| IAM | `iam:GetAccountSummary`, `iam:GetInstanceProfile`, `iam:ListAccountAliases`, `iam:ListRoles`, `iam:GetRole`, `iam:ListRolePolicies`, `iam:GetRolePolicy`, `iam:ListAttachedRolePolicies`, `iam:GetPolicy`, `iam:GetPolicyVersion`, `iam:SimulatePrincipalPolicy` | Reads role trust policies, inline and managed permission policies, and effective permission paths. |
| EC2 | `ec2:DescribeInstances`, `ec2:DescribeIamInstanceProfileAssociations`, `ec2:DescribeLaunchTemplates`, `ec2:DescribeLaunchTemplateVersions`, `ec2:DescribeRegions` | Maps compute workloads, launch-template roles, and instance profiles to IAM roles. |
| ECS | `ecs:DescribeServices`, `ecs:DescribeTaskDefinition`, `ecs:ListClusters`, `ecs:ListServices`, `ecs:ListTaskDefinitions` | Maps ECS services and task definitions to task and execution roles. |
| Lambda | `lambda:ListFunctions`, `lambda:ListEventSourceMappings`, `lambda:ListAliases`, `lambda:ListVersionsByFunction`, `lambda:ListTags` | Maps Lambda functions and event sources to execution roles without invoking functions or reading payloads. |
| CodeBuild | `codebuild:BatchGetProjects`, `codebuild:ListProjects` | Maps build projects to service roles and metadata-only references. |
| CodePipeline | `codepipeline:ListPipelines`, `codepipeline:GetPipeline`, `codepipeline:GetPipelineState` | Maps pipeline deployment roles, stages, artifact stores, and execution state. |
| Step Functions | `states:ListStateMachines`, `states:DescribeStateMachine`, `states:ListTagsForResource` | Maps state-machine roles and service integrations without starting executions. |
| EventBridge / Scheduler / Pipes | `events:ListEventBuses`, `events:ListRules`, `events:ListTargetsByRule`, `events:ListTagsForResource`, `scheduler:ListSchedules`, `scheduler:GetSchedule`, `pipes:ListPipes`, `pipes:DescribePipe` | Maps event-driven targets and roles without publishing events or invoking targets. |
| Managed compute | `apprunner:ListServices`, `apprunner:DescribeService`, `batch:DescribeComputeEnvironments`, `batch:DescribeJobDefinitions`, `glue:GetJobs`, `glue:GetCrawlers`, `elasticmapreduce:ListClusters`, `elasticmapreduce:DescribeCluster` | Maps managed compute workloads and roles without submitting jobs or changing services. |
| EKS | `eks:DescribeCluster`, `eks:DescribeFargateProfile`, `eks:DescribeNodegroup`, `eks:DescribePodIdentityAssociation`, `eks:ListClusters`, `eks:ListFargateProfiles`, `eks:ListNodegroups`, `eks:ListPodIdentityAssociations` | Maps Pod Identity, node, and Fargate roles to EKS workloads. |
| SageMaker | `sagemaker:DescribeDomain`, `sagemaker:DescribeEndpoint`, `sagemaker:DescribeEndpointConfig`, `sagemaker:DescribeModel`, `sagemaker:DescribeNotebookInstance`, `sagemaker:DescribePipeline`, `sagemaker:DescribeProcessingJob`, `sagemaker:DescribeTrainingJob`, `sagemaker:DescribeTransformJob`, `sagemaker:ListDomains`, `sagemaker:ListEndpoints`, `sagemaker:ListModels`, `sagemaker:ListNotebookInstances`, `sagemaker:ListPipelines`, `sagemaker:ListProcessingJobs`, `sagemaker:ListTrainingJobs`, `sagemaker:ListTransformJobs` | Maps notebook, training, processing, transform, model, endpoint, pipeline, and Studio roles without presigned URLs or invocations. |
| S3 | `s3:ListAllMyBuckets`, `s3:GetBucketAcl`, `s3:GetBucketLocation`, `s3:GetBucketOwnershipControls`, `s3:GetBucketPolicy`, `s3:GetBucketPublicAccessBlock`, `s3:GetBucketTagging`, `s3:GetEncryptionConfiguration`, `s3:ListAccessPoints` | Reads bucket metadata and policy edges; never reads object contents. |
| ECR | `ecr:DescribeImages`, `ecr:DescribeRepositories`, `ecr:GetLifecyclePolicy`, `ecr:GetRepositoryPolicy`, `ecr:GetRegistryScanningConfiguration`, `ecr:ListTagsForResource` | Reads repository metadata without reading image layers or manifests. |
| KMS | `kms:ListKeys`, `kms:DescribeKey`, `kms:GetKeyPolicy`, `kms:GetKeyRotationStatus`, `kms:ListAliases`, `kms:ListGrants`, `kms:ListResourceTags` | Reads key metadata and policy edges; never performs cryptographic operations. |
| SQS/SNS | `sqs:ListQueues`, `sqs:GetQueueAttributes`, `sqs:ListQueueTags`, `sns:ListTopics`, `sns:GetTopicAttributes`, `sns:ListSubscriptionsByTopic`, `sns:GetSubscriptionAttributes`, `sns:ListTagsForResource` | Reads queue/topic metadata, resource policies, encryption references, DLQs, and endpoint-redacted subscription metadata. |
| DynamoDB / RDS | `dynamodb:ListTables`, `dynamodb:DescribeTable`, `dynamodb:ListTagsOfResource`, `dynamodb:GetResourcePolicy`, `rds:DescribeDBInstances`, `rds:DescribeDBClusters`, `rds:DescribeDBProxies`, `rds:ListTagsForResource` | Reads table, cluster, proxy, policy, and tag metadata without reading rows. |
| Secrets Manager | `secretsmanager:ListSecrets`, `secretsmanager:DescribeSecret`, `secretsmanager:GetResourcePolicy`, `secretsmanager:ListSecretVersionIds` | Reads secret metadata, policies, and version stages without reading secret values. |
| SSM Parameter Store | `ssm:DescribeParameters`, `ssm:ListTagsForResource` | Reads parameter metadata and tags without retrieving parameter values or history. |
| Bedrock AgentCore | `bedrock-agentcore:ListAgentRuntimes`, `bedrock-agentcore:GetAgentRuntime`, `bedrock-agentcore:ListAgentRuntimeEndpoints`, `bedrock-agentcore:ListGateways`, `bedrock-agentcore:GetGateway`, `bedrock-agentcore:ListGatewayTargets`, `bedrock-agentcore:GetGatewayTarget`, `bedrock-agentcore:ListMemories`, `bedrock-agentcore:GetMemory`, `bedrock-agentcore:ListBrowsers`, `bedrock-agentcore:GetBrowser`, `bedrock-agentcore:ListCodeInterpreters`, `bedrock-agentcore:GetCodeInterpreter` | Reads AgentCore runtime, gateway, and capability metadata without invoking agents or reading customer payloads. |
| Organizations / CloudFormation | `organizations:DescribeOrganization`, `organizations:ListRoots`, `organizations:ListOrganizationalUnitsForParent`, `organizations:ListAccountsForParent`, `organizations:ListDelegatedAdministrators`, `organizations:ListDelegatedServicesForAccount`, `cloudformation:ListStackInstances` | Resolves organization and OU membership and verifies the read-only connector StackSet in each targeted account. These calls are used only for organization-scoped connectors. |

The CloudFormation template requires an External ID condition in the trust policy. Identrail generates a unique 32-byte External ID per connector and stores it in the connector secret envelope table, not plaintext connector metadata.
